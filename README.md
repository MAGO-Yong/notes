# 个人知识库与笔记

## 目录结构

```
.
├── inbox/              # 待整理的新笔记
├── active/             # 正在使用的笔记
│   ├── 2026-W11/       # 按周组织（当前周）
│   ├── 2026-W12/       # 下周
│   └── ...
├── archive/            # 归档内容
│   ├── 2026-Q1/        # 第一季度（1-3月）
│   ├── 2026-Q2/        # 第二季度（4-6月）
│   └── ...
└── templates/          # 笔记模板
```

## 使用规范

1. **inbox/**: 新笔记先放这里，整理后移动到 active/当周目录
2. **active/**: 当前活跃的笔记，**按周组织**（格式：YYYY-W周数）
3. **archive/**: 不再活跃的笔记，**按季度归档**（格式：YYYY-Q季度）
4. **templates/**: 常用的笔记模板

## 时间维度说明

- **周**: 全年 52 周，每周一个目录（如 2026-W11 表示第11周）
- **季度**: 每3个月一个季度（Q1:1-3月, Q2:4-6月, Q3:7-9月, Q4:10-12月）
- **归档规则**: 超过 4 周的笔记移至 archive/对应季度

## 备份说明

- 每日自动备份
- 重要变更及时提交
- 使用有意义的 commit message
