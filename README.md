# 个人知识库与笔记

## 目录结构

```
.
├── inbox/          # 待整理的新笔记
├── active/         # 正在使用的笔记
│   ├── 2026-03/    # 按月份组织
│   └── projects/   # 按项目组织
├── archive/        # 归档内容
│   └── 2026/       # 按年份归档
└── templates/      # 笔记模板
```

## 使用规范

1. **inbox/**: 新笔记先放这里，整理后移动到 active/
2. **active/**: 当前活跃的笔记，按月份或项目分类
3. **archive/**: 不再活跃的笔记，按年份归档
4. **templates/**: 常用的笔记模板

## 备份说明

- 每日自动备份
- 重要变更及时提交
- 使用有意义的 commit message
